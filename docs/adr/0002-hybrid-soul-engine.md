# 靈魂引擎採混合式：預寫台詞優先，只有聊天用雲端 AI

日常反應、鬥嘴和抱抱都用作者寫的台詞與規則，只有主人用自己的話聊天時才呼叫雲端 AI；AI 失敗時回到預寫台詞。這樣個性穩定、費用可控，沒網路也能陪伴。全用 AI 的費用與失控風險較高，全部預寫則無法真正回應主人說的話。

預寫台詞全由作者撰寫，開發時也不用 AI 產生。這樣語氣最道地，也沒有資料外傳的問題，但台詞量增加最慢，較容易重複。

代價是兩套系統的語氣要調到一致，所以兩者都以[角色聖經](../characters/bible.md)為來源。
