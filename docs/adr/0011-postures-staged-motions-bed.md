# 躺姿是另一個造型，動作可以分段帶位移，角色可以在家具上（擴充 ADR 0009、0010）

## 背景

A1 第 13 項的睡覺（v0.0.11）。作者 2026-11-24 在私有素材 repo 的原型把仰睡定案：造型、兩隻在床上的位置、影子、呼吸；並決定先只把仰睡放進 App，趴睡、側躺、大字之後再做。玩法見[遊戲設計的睏意](../product/game-design.md#睏意打瞌睡與睡覺)。

照 [ADR 0009](0009-characters-species-motion-data.md)、[ADR 0010](0010-motion-visibility-loops-effects.md)，App 還做不到：

| 需要 | 現在 |
|---|---|
| 躺著的造型：順著床的斜度重新畫，和站著的部件、畫布、外形都不同 | 造型只有正面與斜向四個方向 |
| 床上的影子：半透明，在角色底下 | 角色的部件只有不透明的顏色；特效畫在角色上面 |
| 上床：蹲一下跳上床 → 走到床位 → 轉正面坐下閉眼 → 躺平；醒來再反過來 | 一個動作只有一個方向的片段，播的時候不會移動 |
| 站在、躺在床上：離地 10 單位，蓋在床上面 | 位置只有地板上的 (i, j)；站得上去的格子不含家具 |
| 點躺著的那隻 | 觸控範圍是整張角色畫布，兩隻躺著時重疊很多，會叫醒錯的那隻 |
| 睏了去床上睡 | 睏意只會觸發打瞌睡 |

## 決定

### 造型：方向之外多一種「姿勢」

- `vector.json` 多一組 `postures`：名稱 → 造型，內容和 `facings` 的一個方向相同（畫布、放到箱庭上的那一點、畫的先後、部件）。仰睡叫 `lieBack`。
- 姿勢沒有方向，不翻轉。片段可以指定用哪個姿勢；狀態機與閒晃不知道有姿勢。
- 姿勢可以寫 `touch`：一個凸多邊形，是這個姿勢的觸控範圍。沒寫的照舊用整張畫布。
- 姿勢可以寫 `shadow`：形狀、顏色、不透明度。畫在那隻角色的外框之前，不跟著部件動。形狀先合成一張再乘不透明度，重疊處不會變深。
- 片段照樣可以換部件：仰睡的圓眼是平常藏起來的部件。

### 動作可以分段，每段可以帶位移

- `motion.json` 升到第 4 版。動作除了原本的寫法（每個方向一段片段），可以改寫 `stages`，依序播：

  ```
  "climbIn": { "stages": [
    { "look": "backLeft", "duration": 1.0, "clip": <片段>, "travel": { "from": "entry", "to": "edge", "keys": [[秒, 比例, 另外離地幾單位], ...] } },
    { "look": "backLeft", "duration": 0.6, "clip": <片段>, "travel": { "from": "edge", "to": "slot", ... } },
    { "look": "front",    "duration": 0.6, "clip": <片段> },
    { "look": "lieBack",  "duration": 0.3, "clip": <片段> } ] }
  ```

- `look` 是方向或姿勢的名稱。段與段之間直接切換，沒有過場（作者 2026-11-23 決定）。
- `travel` 的端點是箱庭給的：上床前站的那一格（`entry`）、床邊（`edge`）、床位（`slot`）。動作資料不知道床在哪裡，換一張床不用重新匯出。
- 位置由模擬照 `travel` 算（模擬是唯一的世界狀態，[ADR 0008](0008-simulation-frame-render-layers.md)），部件怎麼動照樣由畫面準備播片段。
- 睡覺要的動作：`climbIn`（上床躺下）、`sleep`（循環）、`wakeTapped`（被點：換成坐著揉眼睛，再下床）、`wakeRested`（睡飽：換成坐著伸懶腰，再下床）。
- `sleep` 一個循環 8 秒：呼吸 4 秒一次，Z 每 1.6 秒冒一個，剛好接得上。

### 箱庭：床有床位，角色可以在家具上

- 床從 3×2 改成 **3×3** 格（作者看原型時選的）。
- 家具可以有床位：躺的那一點、床邊、上床前站哪一格（可以有好幾個，依偏好排）。A1 的床有兩個：`(1.85, 2)` 與 `(1.85, 3.45)`（作者 2026-11-24 定案）。
- **床位先到先選**（作者 2026-11-24 決定）：
  - 走到床邊、開始上床的那一刻選床位，挑離牠近的空床位，選了就佔住，下床落地才放開。
  - 走去床邊的路上，目標的床位被別隻先佔走：改去另一個空的。
  - 沒有空床位時不去床上睡，照樣可以打瞌睡。
- 模擬的位置多了離地高度與「在哪件家具上」。在家具上的角色一定畫在那件家具前面；角色之間照樣比腳底高度。
- 上床前站的那一格被擋住：照走路的規則等、繞路，還是不行就放棄，回到待機。
- 下床時每個落地的格子都被佔住：停在床邊等。

### 狀態機與睏意

- 待機 →（要牠去睡）→ 走去床邊 → 上床 → 睡覺 →（睡飽）→ 伸懶腰下床 → 待機；睡覺時被點 → 揉眼睛下床 → 待機，另一隻繼續睡。
- 走去床邊時被點，照走路的規則（哈囉完接著走）。上床、醒來、下床播放中再點不理（作者 2026-11-24 決定）。
- 睡飽要等 `sleep` 播完那一個循環才醒，和打瞌睡相同。
- **觸發**（作者 2026-11-24 決定）：睏意到 90，閒晃挑下一件事時有 50% 的機率去床上睡；到 100 一定去。中間沿用打瞌睡越睏機率越高的寫法：每多 5 點加 25%（90 是 50%、95 是 75%、100 是 100%）。
- 先看要不要睡覺，沒有才看要不要打瞌睡。不打斷正在做的事。
- `wander.json` 升到第 4 版，`sleepiness` 多一組 `sleep`，欄位和 `doze` 相同：門檻、機率、越睏機率越高、下降速度、醒來的值、冷卻。初始數字（實機上調）：每分鐘降 40、降到 15 醒。
- **打瞌睡的冷卻從 1 分鐘改成 10 分鐘**（作者 2026-11-24 決定）：照 v0.0.10 的數字，睏意到不了 90。2026-11-24 用近似的模擬跑 300 次、每次 6 小時（走路的步數是估的）：

  | 打瞌睡的設定 | 打瞌睡 | 睡覺 | 最高睏意（平均） |
  |---|---|---|---|
  | v0.0.10（冷卻 1 分鐘） | 每小時 12.5 次 | 一次都沒有 | 73 |
  | 冷卻 5 分鐘 | 每小時 8.7 次 | 一次都沒有 | 79 |
  | 冷卻 8 分鐘 | 每小時 5.3 次 | 每小時 0.4 次 | 92 |
  | 冷卻 10 分鐘 | 每小時 2.8 次 | 每小時 2.7 次 | 96 |
  | 冷卻 1 分鐘，機率固定 3% | 每小時 2.7 次 | 每小時 2.4 次 | 96 |

- 還沒有日夜，先照睏意醒；等天亮在第 21 項接上。

### 匯出

- 躺姿照原型的算式，從正面造型（臉、眼睛、帽子、顏色）加上每隻的數字產生，搬進私有素材 repo 的向量工具；App 只讀結果。
- 原型的外形是很密的折線，匯出時簡化到誤差 0.02 單位以內（貼圖一個像素是 0.0625 單位）。一隻躺姿的 JSON 從約 270KB 變成約 90KB。用裁切擋住的部分也裁掉，貼圖才不會白佔空間。

## 代價

- **記憶體**：只加仰睡，兩隻的貼圖從 31,610KB 變成 44,874KB，是 50MB 上限的 88%（2026-11-25 在 3 倍螢幕的模擬器量）。在上限內，但**第三隻上台或第二個睡姿之前一定要先省**。四個睡姿全加估 87,667KB（其中三個還是舊畫法），作者說先不管，加第二個睡姿之前再討論。
- **躺姿只畫了一個床的方向**（床頭靠左牆）。床能轉方向時要翻轉或另外畫。這是假設，現在不做。
- **影子的形狀照床是平的來畫**：躺在地上、沙發上要另外看。
- **影子不裁切**：在定案的床位，影子超出床面 0.017 格，比外框還細。床位改得更靠邊時要在匯出時縮小。
- **觸控範圍另外存一份**：外形改了，匯出時一起重算。
- **動作有兩種寫法**（每個方向一段、分段）：讀檔與檢查都要支援；打瞌睡、哈囉不動。
- **床變大**：3×3 會佔掉 j = 3 那一排三格，家具旁邊能站的格子跟著變。

## 沒有選的做法

- **把躺姿的部件藏在正面造型裡**：格式不用改，但每多一個睡姿，正面就多九個左右藏起來的部件，畫布與觸控範圍也是站著的。
- **上床拆成很多個狀態**（跳、走、坐、躺各一個）：狀態機會多出約八個狀態，而且都只是依序播完；分段把順序留在資料裡。
- **影子用不透明的顏色畫**：床是單一顏色時看起來一樣，但會蓋掉後面那隻的身體，換床的顏色也要改。
- **兩隻呼吸對齊**：入睡時要從呼吸的中間接上，會跳一下。作者 2026-11-24 決定不對齊：各自從躺下開始算，速度一樣。
- **每隻固定一個床位**：原型原本的做法。作者 2026-11-24 改成先到先選；原型可以看兩隻對調的樣子。

## 定案

提案時的條件：

- 測試全過，含姿勢、分段帶位移、床位（先到先選、被佔走、沒有空位）、前後順序、觸控範圍，從角色包一直到繪製清單；假鯊魚（沒有姿勢、沒有睡覺的動作）照樣能跑，而且不會去睡。
- 記憶體預算的測試通過。
- 作者在 iPhone 上看過兩隻上床、睡覺、被點醒一隻、睡飽自己下床，和原型一樣。

2026-11-25 實作完成（v0.0.11）：256 個測試全過，含記憶體預算；兩隻的新動作和 `vector.js` 的算式逐格比對都相同。作者 2026-11-25 在 iPhone 上測過，通過，定案。
