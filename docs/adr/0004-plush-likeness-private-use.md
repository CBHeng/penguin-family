# 照玩偶原樣僅限自用與小範圍，造型必須可替換

為了最強的情感連結，第一階段直接使用玩偶的造型。但玩偶是市售品（作者於 2026-11-04 確認），造型可能有他人的著作權或商標，所以目前只限作者自用，repo 也保持私有。

分享給親友（A2）前，要由作者決定改為原創造型、取得授權，或在了解風險後維持原樣。公開上架前則必須改為原創造型或取得授權。因此造型要做成可替換的角色包，換造型時不用改程式。
