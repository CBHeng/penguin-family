# 角色與箱庭改走平面向量

[ADR 0005](0005-pixel-art-swiftui.md) 決定角色與箱庭走像素。第一隻在 iPhone 11 上走起來後，作者覺得「動起來的時候，有些感覺很像破版」。2026-11-18 逐格看哈囉、小跑與模擬器連拍，找到兩個來源：

- **圖本身**：部件在 44×45 格的小圖上旋轉、傾斜，只能整格移動。揮手的手變成細細一根、邊緣斷掉，身體壓扁時紅披肩斷成階梯，小跑前傾（每列往旁邊挪）時頭和帽子每一格都跳一下。這是在低解析度上用程式變形的限制，要消除只能逐格手修。
- **位置**：企鵝每秒移動 12 次、一次一整個像素，鏡頭卻每秒 60 次平滑跟著牠，結果企鵝在畫面上一頓一頓地前後抖。這是程式的問題，和畫風無關。

私有素材 repo 做了比較網頁（第一隻的資料夾裡的 `vector/compare/compare.html`）：像素版照 App 的合成移植，哈囉 56 格和 Python 逐格相同；向量版用同樣的形狀、轉軸與時間軸，只把整格移動換成平滑的旋轉與縮放。另外並排了「現在的移動」「像素圖、平滑移動」「向量、平滑移動」。作者看過比較與技術取捨（見[調查](../research/asset-and-engine.md#改走向量的技術評估查證日期2026-11-18)）後，2026-11-18 決定換向量。

## 決定

- **角色與箱庭改用平面向量。** 形狀（橢圓、曲線路徑）寫成資料，部件可以連續旋轉、縮放、平移；位置不取整數，移動平滑。外觀從比較網頁的向量版開始，和作者一起調。
- **維持原生 Swift 與 Metal。** ADR 0005 選原生、ADR 0006 選 Metal 與「有變化才畫」的遊戲迴圈都不變。0006 的理由裡「像素保證對齊」不再適用，其餘（效能上限、長期最穩）仍成立。
- **繪圖方式**：
  - 企鵝：載入時用 Core Graphics 把每個部件畫成貼圖（解析度照最大倍率，加 mipmap），每一格依姿勢在 Metal 轉動、縮放貼圖。外框分兩次畫：先畫整隻的外框剪影，再畫各部件的顏色，部件重疊處才不會多出內線。
  - 箱庭：平面色塊直接切成多邊形交給 GPU 畫，邊緣用多重取樣抗鋸齒（MSAA）；任何倍率都清楚，也不用準備大張貼圖。
- **形狀格式自己定，不讀 SVG 檔、不加套件。** iOS 沒查到公開的 API 能在執行時讀 SVG 檔，角色包又是從資料夾讀的；現在的部件本來就是橢圓加少數曲線。
- **素材工具改用 JS**（作者 2026-11-18 決定）：私有素材 repo 的向量形狀、瀏覽器預覽與匯出共用同一份 JS，匯出用 Node，不裝 npm 套件。原本的約定是「只用 Python 標準函式庫」，但它畫不出平滑的圖，預覽一定要在瀏覽器看。
- **順序**（作者 2026-11-18 決定）：先換完向量，再做 A1 的閒晃。

## 影響

- **換完後拿掉**：小部件只移不轉、整列平移的前傾、縮放吸附到整數倍、鏡頭對齊實體像素，以及像素合成（`RigCompositor`、`ObliqueCompositor`、`PixelGrid`）與 Python、Swift 的逐像素比對。
- **不受影響**：找路、房間格子、等角換算（數學不變，只是不取整數）、舞台的走路與前後排序、行為狀態機、事件紀錄、遊戲迴圈、點擊判斷（用圖的外框方塊）。
- **驗證方式改變**：抗鋸齒在瀏覽器、Core Graphics、Metal 各不相同，預覽和 App 不再逐像素相同。改成比對每一格的姿勢數字（時間軸本來就這樣測），畫面看截圖。
- **記憶體**：企鵝部件準備到抱抱的倍率（每單位 8pt）、含 mipmap。用第一隻的 `vector.json` 算，一個方向在 iPhone 11 約 3.6MB、螢幕 3 倍的機型約 8.1MB；兩隻、三個方向推估約 22MB 與 49MB，3 倍機型接近 50MB 的門檻，需要時把外框貼圖改成單色或只準備到 7pt。（2026-11-18 第 9 項實測：一隻三個方向在螢幕 3 倍的模擬器約 31MB，比這個推估多，兩隻在 3 倍的手機會超過門檻；見[架構](../architecture.md#技術取捨)。）箱庭如果畫成一張大圖，抱抱倍率在 iPhone 11 約 77MB，超過 50MB 的門檻，所以箱庭用多邊形。
- **要重畫**：第一隻的正面、哈囉、斜向（左前、左後，右邊翻轉）。慢走、小跑的節奏與走法沿用。
- **比例**：「看起來有點扁」（A1 的比例項目）在向量版只要改形狀的數字，連帶的角度與動作不用逐格重畫。
- **願景的「2.5D 箱庭」改指平面向量的等角箱庭。**

## 定案

提案時的條件：App 內用向量畫出第一隻的正面、哈囉與箱庭，作者在 iPhone 11 上看過動起來不破、認得出是牠，並在正式版量記憶體與 Animation Hitches。

2026-11-18 App 內實驗完成（A1 第 8 項），裝到 iPhone 11。作者自己在實機上量過效能，覺得沒問題，決定不再另外錄 Animation Hitches，直接定案。量到的數字沒有記下來。
